# 人群与身份

「这就是生活」：一类人在街上、在家里、在单位里**通常**是什么样。不是审美风格，是观察。
每条按维度给切口，全是名词和动作。用的时候挑最能说明这个人的 5–8 条，再按 `../archetype-methods.md` 的「具体 + 反转」拉回一个具体的人：**这里写的是统计上常见的样子，是起点，不是这个人。**

时代默认是 2020 年代中国大陆城市（另有说明除外）；别的年代、地区，按 `../review-checklist.md` 的时代考据去改。
可见距离同维度词库：〔全〕〔中〕〔特〕。

## 年龄

### 城市老年男性（70 岁上下，退休职工）

- 脸与身体：老年斑在颧骨和手背；眉毛长出几根特别长的寿眉；耳朵大、耳垂长；背微驼，走路小步、脚抬得不高〔全〕
- 发型：花白短发，鬓角推得很短，头顶稀；或者染得过黑、发根露出一截白〔中〕
- 服装：浅灰或藏青夹克（拉链拉到胸口），里面一件洗软的格子衬衫扣到最上面；深色西裤腰提得很高、裤线早没了；冬天加一件枣红或深灰的手织毛背心〔全〕
- 鞋：黑色老布鞋（千层底、松紧口），鞋面上落着一层灰；或者黑色软皮系带鞋，鞋头起皱〔中〕
- 随身：保温杯（不锈钢、杯身有凹痕）、老花镜挂在胸前口袋、一只装菜的布袋或红白蓝塑料袋；手腕上一块钢带老表〔中〕
- 生活痕迹：手背青筋凸起、指甲厚而发黄；嘴里有一两颗假牙〔特〕
- 动作：双手背在身后走路；站着时轻轻晃身体；坐下前先用手扶住膝盖
- 说话：嗓门大（耳朵背了）、同一件事讲三遍；爱说「我们那时候」

### 城市老年女性（广场舞 / 带孙辈）

- 脸与身体：脸圆、两颊下垂，烫过的眉毛（纹眉）颜色发青〔中〕
- 发型：短卷发（小卷烫）、染成酒红或黑褐，头顶蓬起〔全〕
- 服装：印花雪纺或针织开衫（大花、玫红、孔雀蓝），里面高领打底；裤子是黑色弹力裤或阔腿裤；跳舞时一件统一的亮色队服〔全〕
- 鞋：黑色软底运动鞋或「妈妈鞋」（魔术贴、坡跟）〔中〕
- 随身：丝巾系在脖子上或绑在包带上；腰包；孙子的水壶和小外套搭在手臂上〔中〕
- 动作：边走边和熟人打招呼；一只手拽着孙子的胳膊
- 说话：语速快、声音高；见面就问「吃了吗」「你家孩子找对象没」

### 农村老年人

- 脸与身体：脸和脖子晒成深棕、皱纹深得像刻上去；眼角皱纹里没晒到的地方发白；手大、指节粗、掌心老茧发黄〔中〕
- 发型：男的推得很短的白发茬；女的齐耳短发用黑发卡别在耳后〔中〕
- 服装：男的深蓝或军绿旧外套（儿女淘汰下来的，比本人大一号），里面套两三件；女的碎花罩衣（防脏的那种）套在棉袄外面〔全〕
- 鞋：解放鞋或黑布鞋，鞋帮上有干了的泥；夏天塑料凉鞋〔中〕
- 随身：旱烟袋或廉价香烟夹在耳朵上；一根当拐杖用的木棍〔中〕
- 动作：蹲着（脚跟着地）和人说话；手背在身后看庄稼
- 说话：方言重、话少，说完一句停很久

### 青春期中学生（14–17 岁）

- 身体：身体抽条但肩还没长开、手脚显长；脸上冒几颗青春痘（额头、下巴）〔中〕
- 发型：男生碎盖刘海盖到眉毛（学校规定不能染烫）；女生高马尾或齐肩，碎发用黑发夹别住〔全〕
- 服装：蓝白或红白运动款校服，外套拉链敞着、袖子撸到手肘；校服裤裤腿偷偷改窄过；里面一件自己的 T 恤露出领口〔全〕
- 鞋：白色运动鞋（鞋头刷得很白，或者已经灰了）〔中〕
- 随身：双肩包只背一边；手腕上一根黑色发圈（女生）或电子表（男生）；指甲缝里有笔油〔中〕
- 动作：低头看手机走路；三五成群勾肩搭背
- 说话：网络梗多、一句话里「绝了」「无语」；跟大人说话三个字以内

### 大学生

- 服装：卫衣 + 运动裤 / 工装裤；冬天长款羽绒服；拖鞋去食堂〔全〕
- 随身：帆布托特（印着学校或展览的字）、电脑包、外卖袋；耳机挂在脖子上〔中〕
- 生活痕迹：熬夜的黑眼圈、下巴冒痘〔特〕
- 动作：边走边打电话、在图书馆趴着睡
- 说话：「救命」「我不行了」挂嘴边

## 知识分子

### 老派知识分子（大学教授 / 研究员，60 岁上下）

- 风格参照：`服装风格.md` 的「知识分子风」
- 脸与身体：长期伏案，肩微圆、头前伸；眉间一道竖纹〔中〕
- 发型：花白、往后梳但不抹油，几缕翘着；或者谢顶留侧边〔中〕
- 服装：灰色或驼色开衫 / 针织背心套在浅蓝牛津衬衫外面；深灰或卡其灯芯绒裤；春秋一件旧的粗花呢西装外套，手肘磨得发亮〔全〕〔中〕
- 鞋：棕色系带皮鞋，鞋头磨白〔中〕
- 随身：金属细框或玳瑁圆框眼镜（看书时推到额头上）；上衣口袋插两支笔；一只装满书的旧公文包或帆布袋；一个泡着茶叶的玻璃杯〔中〕
- 生活痕迹：右手中指第一节侧面的写字茧；指尖有粉笔灰或墨水印〔特〕
- 动作：说话前先推一下眼镜；思考时手指敲桌面；走路慢、边走边想事
- 说话：语速慢、句子长，爱用「这个问题要分两方面看」；纠正别人用词

### 当代青年学者 / 博士生

- 服装：素色 T 恤或格子衬衫 + 外面一件深色冲锋衣或针织开衫；直筒裤；运动鞋〔全〕
- 随身：笔记本电脑贴满会议贴纸；帆布包；细框眼镜〔中〕
- 生活痕迹：黑眼圈、发际线开始后退〔中〕
- 说话：中英夹杂、爱说「其实这个有文献的」

### 文人 / 作家 / 编辑

- 服装：中式立领或棉麻衬衫、宽松长裤、布鞋；或者一身黑〔全〕
- 随身：烟（手指熏黄）、茶杯、钢笔；手串〔中〕
- 动作：说话时眼睛不看人、看远处
- 说话：慢、停顿多、引用多

## 城市职业

### 外卖骑手

- 服装：平台颜色的冲锋衣或马甲（黄 / 蓝），反光条发灰；冬天加一件挡风护膝和棉手套；夏天冰袖〔全〕
- 随身：头盔（扣带挂在下巴下，或者顶在头上）、手机支架、腰间一串钥匙〔中〕
- 生活痕迹：脸和手背晒黑、手腕以上发白（冰袖 / 手套印）；额头一圈头盔压痕、头发压扁〔中〕
- 动作：边走边看手机、小跑上楼；等电梯时脚一直点地
- 说话：快、短；「放门口了」「您好外卖」

### 建筑工人

- 服装：迷彩或灰色工装裤（膝盖磨薄）、旧 T 恤或背心、反光背心洗得发灰；安全帽（帽檐有裂、内衬发黄）〔全〕
- 鞋：解放鞋或劳保鞋，鞋头钢包头磨出来〔中〕
- 生活痕迹：手掌和虎口厚茧、指甲缝发黑、小臂粗；脖子后面晒成深棕〔中〕
- 动作：午饭蹲在路边吃盒饭；抽烟时手指夹烟的位置很靠里
- 说话：方言，爱叫人「老乡」「师傅」

### 出租车 / 网约车司机

- 服装：深色夹克或 POLO 衫，肚子凸起；夏天一件白背心〔全〕
- 随身：茶杯放在杯架（茶叶泡了一整天）；手机两部；车里挂一串佛珠或平安符〔中〕
- 生活痕迹：左手小臂比右手黑（开窗晒的）；腰不好，坐下时手撑一下〔中〕
- 说话：聊政治和房价，「我跟你说……」

### 菜市场摊主

- 服装：深色围裙（胶面或帆布）挂着腰包；袖套；冬天军大衣或羽绒背心〔全〕
- 随身：腰包里一沓零钱和收款码；一把电子秤；一顶遮阳帽〔中〕
- 生活痕迹：手指被水泡白、指甲边破口；手背被冻得发红〔特〕
- 说话：嗓门大、算账快；「给你抹个零」

### 写字楼白领 / 程序员

- 服装：程序员：格子衬衫或纯色卫衣、冲锋衣、牛仔裤；白领：衬衫 + 西裤或针织 + 半身裙，工牌挂在脖子上〔全〕
- 随身：双肩电脑包、降噪耳机、一杯套着纸杯套的外带咖啡（写素色纸杯，不写品牌和标志）〔中〕
- 生活痕迹：圆肩、头前伸、颈纹；黑眼圈；手腕下面压出的红印（压着桌沿打字）〔中〕〔特〕
- 动作：等电梯时刷手机；开会时转笔
- 说话：「对齐一下」「我同步一下」「这个需求」

### 销售 / 中介

- 见 `../dimensions/索引.md`「精明的销售 / 中介」

### 体制内（基层公务员 / 国企中层）

- 服装：白衬衫或浅蓝衬衫塞进深色西裤、黑色皮带板扣、黑皮鞋；冬天深色夹克（行政夹克，翻领、拉链）〔全〕
- 随身：黑色公文包或手包夹在腋下；保温杯；一部旧款手机套着皮套〔中〕
- 动作：走路不急不慢、腰板挺；开会时笔记本摊开却不写
- 说话：「这个事情我们研究一下」「原则上」

### 老板 / 暴发户（小城市）

- 服装：POLO 衫领子立起，或者大 logo 腰带（不写 logo，写「镶金属大方扣的皮带」）；一身「看起来贵」的深色衣服〔全〕
- 随身：粗金链子、金表、手包；两部手机；车钥匙放在桌上显眼的位置〔中〕
- 生活痕迹：啤酒肚、脸色红润发油、手指上一枚金戒〔中〕
- 动作：坐下就跷腿、往后靠；说话时用手指点人
- 说话：嗓门大、叫人「小 X」；「这都不是事儿」

### 主播 / 网红

- 脸：妆面精致、眉毛和睫毛做过；离开镜头时脸上是累的〔中〕
- 服装：镜头里的上半身很精致，下半身是睡裤和拖鞋（这个反差就是生活）〔全〕
- 随身：补光灯、手机支架、领夹麦〔中〕
- 说话：镜头前语调高、尾音上扬、「家人们」；关了直播立刻沉默

### 医生 / 护士

- 服装：白大褂（口袋里插着笔、手电、叠起来的单子），里面刷手服（蓝 / 绿）；护士帽或发网〔全〕
- 随身：工牌、听诊器挂在脖子上〔中〕
- 生活痕迹：手干、发红起皮（频繁洗手消毒）；黑眼圈；口罩勒出的耳后红印和鼻梁压痕〔特〕
- 动作：走路快、边走边看病历；吃饭很快
- 说话：短、准，用术语

### 厨师（饭店后厨）

- 服装：白色或黑色厨师服、围裙上一片油渍；头上一顶厨师帽或包头巾〔全〕
- 生活痕迹：小臂和手背的细小烫疤、刀疤；手指被热锅烫出的硬皮〔中〕〔特〕
- 动作：毛巾搭在肩上；站着时重心不停换脚
- 说话：后厨里嗓门大、脏话多

## 城乡与圈层

### 小镇青年（三四线城市，20 岁上下）

- 发型：染过的黄 / 灰发长出黑发根；侧边推短、顶上纹理烫〔全〕
- 服装：仿大牌的印花 T 恤或卫衣、修身小脚裤、豆豆鞋或厚底运动鞋〔全〕
- 随身：电动车钥匙、一部屏幕裂了的手机、蓝牙耳机〔中〕
- 动作：骑电动车单手扶把；在烧烤摊和朋友喝啤酒
- 说话：方言 + 网络流行语

### 富二代 / 留学回来的

- 服装：看不出牌子但面料极好的素色卫衣或针织；宽松裤；限量球鞋（鞋底几乎没磨）〔全〕
- 随身：一块素表盘的机械表、车钥匙、一杯手冲咖啡〔中〕
- 生活痕迹：手白净、指甲修得整齐；皮肤状态好（护理过）〔特〕
- 说话：中英夹杂、对价格没概念；「还好吧」

### 全职妈妈（孩子 3 岁以下）

- 发型：随手一个抓夹把头发夹起来，碎发掉下来〔全〕
- 服装：宽松的家居服或运动套装，肩上一块孩子吐奶 / 口水的印子；平底鞋〔全〕
- 随身：一个装满东西的妈咪包（纸尿裤、湿巾、水杯）〔中〕
- 生活痕迹：黑眼圈、手腕腱鞘处贴着膏药（抱孩子）〔特〕
- 动作：抱孩子时身体一直轻轻晃；一只手抱孩子一只手看手机

### 夜场 / 酒吧从业者

- 服装：黑色紧身或开领衬衫、银饰、手上文身〔全〕
- 生活痕迹：作息颠倒的脸色发灰、眼下青黑；烟嗓〔中〕
- 说话：会说话、会调笑、会察言观色

## 写法提醒

- 同一类人至少写一个**和刻板印象相反的细节**（老教授脚上一双很新的跑鞋、外卖骑手头盔里塞着一本书），人就活了。
- 地域和民族特征不要套刻板印象：对照 `../archetypes/11-慎用.md`。
- 这里写不下的，按同样格式往下加：一类人一节，维度切口 + 可见距离。
