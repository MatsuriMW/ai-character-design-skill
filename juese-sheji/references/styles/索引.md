# 风格参考库

做人物设计时，「一个有绅士感的人」「一个知识分子」「一个老年人」「一个民国的教书先生」「赛博朋克的雇佣兵」这类说法，背后其实是一整套已经被总结过的东西：服装风格有经典单品、配色和容易出错的地方；一类人在生活里有他们常穿的鞋、常拿的东西、常有的动作；一个时代、一个圈子、一身制服、一个故事世界，替人决定了大半的穿着。这个库就是这些参考，用来给模式 E 具体化当起点。

| 文件 | 是什么 | 来源 |
|---|---|---|
| `服装风格.md` | 47 个服装 / 审美风格（一个人**选择**怎么穿）：一句话、关键词、经典单品、最小组合、配色 HEX、要当心、细分、参照品牌、风格档案、笔记 | 由 `scripts/sync-styles.py` 从 Obsidian 风格库生成（随 skill 发布的是作者马自立的风格库）；可以换成你自己的 |
| `人群与身份.md` | 一类人在生活里通常的样子（年龄、知识分子、城市职业、城乡圈层）：按维度给切口，带可见距离 | 手写，持续补充 |
| `时代与类型.md` | 时代、圈子、制度和故事世界替人决定的穿着：中国时代（民国 → 九十年代）、欧美时代（1920s → 1980s）、亚文化（嘻哈、机车、西部、杀马特、精神小伙、JK / DK）、制服与职业装、类型片世界（武侠古装按朝代、港片江湖、黑色电影、赛博朋克、蒸汽朋克、太空科幻、中世纪奇幻）；每条带「容易出错」和「写给模型」 | 手写，持续补充 |
| `../dimensions/索引.md` 的「气质词 → 常用切口」 | 轻佻、清冷、苦命、精明、健身这类**气质词**落在哪些维度 | 手写 |

## 什么时候查哪个

用户给的词属于哪一类，就先查哪一个，常常要叠着用：

| 用户说的 | 先查 | 例 |
|---|---|---|
| 一种穿衣风格 / 审美（绅士感、cityboy、老钱、工装、知识分子气、YSL 贵公子、哥特） | `服装风格.md` | 「有绅士感」→ 绅装：合身西装、牛津衬衫、羊毛领带、乐福鞋，藏蓝炭灰，要当心「过于正式显刻板」 |
| 一个时代 / 一个圈子 / 一身制服 / 一个故事世界（民国、八十年代、机车党、空乘、武侠、赛博朋克） | `时代与类型.md` | 「民国教书先生」→ 阴丹士林蓝长衫、圆框眼镜、软呢礼帽，容易出错：长衫配现代手表 |
| 一类人 / 身份 / 年龄 / 职业（老年人、教授、外卖骑手、全职妈妈、小镇青年） | `人群与身份.md` | 「一个老年人」→ 城市老年男性：黑色老布鞋鞋面一层灰、保温杯、老花镜挂在胸前口袋、双手背在身后走路 |
| 一种气质 / 性格（轻佻、清冷、痞、苦相、油腻、禁欲） | `../dimensions/索引.md` | 「轻佻」→ 中分帘发、解到第三颗扣子、重心在一条腿上、尾音上扬 |

叠加：「一个有绅士感的老教授」= 人群（老派知识分子）+ 风格（绅装 / 知识分子风）+ 生活痕迹（写字茧、圆肩）；「八十年代的轻佻青年」= 时代（改开初期到八十年代）+ 气质词（轻佻）。先用时代和人群定这个人活在哪里、过的是什么日子，再用风格定他怎么穿，最后用气质词调动作和说话。

## 怎么落到维度上

1. 从参考里挑 **5–8 条**最能说明这个人的，不要整条照抄（照抄就是刻板印象）。
2. 每条往下切一层：「粗花呢西装外套」→ 款式（三粒扣、贴袋）、面料（人字纹粗花呢、灰棕）、新旧（手肘磨得发亮）、穿法（里面是浅蓝牛津衬衫，没打领带）。切法见 `../dimensions/04-服装.md`。
3. 加上**这个人自己的东西**：一处生活痕迹、一处不完美、一个和刻板印象相反的细节（老教授脚上一双很新的跑鞋）。
4. 风格的「要当心」常常就是破绽或者反转点：知识分子风「容易穿老气」→ 让这个人恰好就穿老气了，袖口起球，这本身就在讲他。
5. 品牌只用来帮你想起具体的样子，锁定段里写款式，不写品牌和 logo。

## 往里加

- **服装风格**：在你的风格库里新建或修改风格页，然后在 skill 目录跑 `python3 scripts/sync-styles.py <风格目录>`（格式见下）。
- **人群与身份**：直接在 `人群与身份.md` 里按格式加一节。
- **时代与类型**：直接在 `时代与类型.md` 里按格式加一节。
- **气质词**：在 `../dimensions/索引.md` 的「气质词 → 常用切口」里加一节。

## 用你自己的风格库

`服装风格.md` 是生成出来的。想换成自己的（或者在作者的基础上加），在 Obsidian 里一个风格建一篇笔记，放在同一个文件夹，frontmatter 照这个写：

```yaml
---
type: 审美风格
类别: 服装风格
排序: 9
层级: 浅水区
关键词: ["西装", "定制", "考究", "复古绅士"]
经典单品: ["合身西装", "牛津衬衫", "羊毛领带", "乐福鞋 / 牛津鞋"]
入门: "一套合身的藏蓝或炭灰西装"
风险: "过于正式会显刻板，用针织、乐福鞋适度软化"
配色: ["#26304A", "#454A56", "#6E5E48"]
品牌: ["Drake's", "Brooks Brothers"]
国内品牌: []
aliases: []
---
> 一句话说清这个风格（第一个引用块会被当成简介）。

## 我的笔记

```

文件名用「风格名（风格）.md」，生成时会去掉「（风格）」。然后在 skill 目录跑：

```bash
python3 scripts/sync-styles.py "<你的风格文件夹>"
```
