# 发型

可见距离：发型轮廓、长度、颜色〔全〕；刘海细节、纹理、发际处理〔中〕；发丝状态、头皮、发根颜色〔特〕。
网上很多叫法混用（比如鲻鱼头和狼尾常被当成一回事），锁定段里**一定带上英文名和结构描述**，别只写中文俗名。

## 发色、发质、状态

| 子项 | 写法 | 英文 | 距离 |
|---|---|---|---|
| 发色 | 纯黑 / 自然黑棕 / 冷棕 / 亚麻 / 灰金 / 漂白 / 挑染（写颜色和位置） / 内层挑染 / 发根长出 3cm 黑色 | jet black / natural dark brown / ash brown / flaxen / ash blonde / bleached / streaks / hidden underlayer color / 3 cm dark roots grown out | 〔全〕/〔特〕 |
| 白发 | 鬓角花白 / 头顶几根白发 / 全白 | greying temples / scattered grey hairs / fully white | 〔中〕 |
| 发质 | 细软 / 粗硬 / 毛躁 / 有光泽 | fine and soft / coarse and stiff / frizzy / glossy | 〔中〕 |
| 状态 | 湿发感（刚洗或抹了发蜡） / 蓬松 / 塌（贴头皮） / 油（发根结缕） / 睡乱了一侧压扁 / 被风吹乱 | wet-look / voluminous / flat against the scalp / greasy clumped roots / bedhead flattened on one side / wind-tousled | 〔中〕 |
| 打理痕迹 | 梳齿痕清楚 / 发胶定型硬 / 刘海挂一缕到眉尾 / 鬓角碎发 / 耳后别着一缕 | visible comb lines / stiff gel hold / one strand falling to the brow tail / loose wisps at the temples / tucked behind one ear | 〔中〕 |
| 发际与碎发 | 发际线边缘有自然疏密 / 额角留少量短发 / 顶部发束弯曲方向不一、松散分开 / 太阳穴附近细碎飞发 | subtle variation along the hairline / short baby hairs at the temples / loosely separated hair strands / fine flyaway hairs around the temples | 〔中〕/〔特〕 |

头发越像一顶完整光滑的头盔（一整块黑色块面、发际线一刀齐），AI 感越明显。近景、大头照里，「发际与碎发」这一行至少挑一项写；背头、油头这类本来就服帖的，写发际边缘的疏密和一两缕没梳进去的碎发。

## 按九项顺序写（男生发型）

只写「帅气短发」「韩系发型」「高级感发型」，模型每次给的刘海、长度、纹理都不一样。上面表里的名称只是起点，锁定段按下面九项依次写完，模型才没有空可以自己补：

**整体长度 → 顶部层次 → 头发纹理 → 分缝方式 → 刘海方向和长度 → 两侧鬓角形状 → 后脑勺轮廓 → 发色 → 发丝质感（自然 / 哑光 / 有光泽）**

| 项 | 写什么 | 例 | 距离 |
|---|---|---|---|
| 1 整体长度 | 发型名 + 大致长度（cm） | 中短碎发，顶部约 6cm / short-to-medium textured cut | 〔全〕 |
| 2 顶部层次 | 有没有层次、蓬不蓬、往哪个方向立 | 顶部保留自然层次，轻微蓬松 / natural layering on top, slight lift | 〔全〕〔中〕 |
| 3 头发纹理 | 直 / 碎 / 束状 / 卷，卷写卷度 | 细碎纹理 / fine piece-y texture | 〔中〕 |
| 4 分缝方式 | 无分缝 / 中分 / 三七 / 二八，分在哪一侧 | 无明显分缝 / no defined part | 〔中〕 |
| 5 刘海方向和长度 | 往前 / 往一侧 / 往后，盖到哪、露多少额头 | 刘海向前略微分开，额头露出少量 / fringe forward, slightly split, a little forehead showing | 〔中〕 |
| 6 两侧鬓角 | 收窄 / 贴头皮 / 铲青 / 渐变起点 / 盖耳 | 两侧鬓角自然收窄 / sides naturally tapered | 〔全〕〔中〕 |
| 7 后脑勺轮廓 | 圆 / 平 / 留长 / 渐变，发尾到哪 | 后脑勺圆润轮廓，发尾修短不过领口 / rounded back, neckline trimmed short | 〔全〕 |
| 8 发色 | 按下面「发色」那一行写 | 深棕黑 / very dark brown-black | 〔全〕 |
| 9 发丝质感 | 自然 / 哑光 / 有光泽 / 湿发感 | 哑光自然发丝 / matte, natural strands | 〔中〕 |

模板（中文；英文锁定段照同样顺序写）：

```
男生发型，{整体长度}，{顶部层次}，{头发纹理}，{分缝方式}，{刘海方向和长度}，{两侧鬓角形状}，{后脑勺轮廓}，{发色}，{自然或哑光的发丝质感}。
```

例：

```
男生中短碎发，顶部保留自然层次和轻微蓬松感，发丝呈细碎纹理，刘海向前并略微分开，额头露出少量，两侧鬓角自然收窄，后脑勺圆润、发尾修短，深棕黑发色，哑光自然发丝质感。
```

```
Male short-to-medium textured cut, natural layering on top with slight volume, fine piece-y texture, fringe falling forward and slightly split with a little forehead showing, sides naturally tapered, rounded back with a short neckline, very dark brown-black hair, matte natural strands.
```

**换发型（图生图 / 已有角色卡）**：长相是身份层，发型的打理方式是造型层（见 `articulate-rules.md`），只换造型层时九项后面接一句锁住其余部分：

```
保持人物的脸型、五官、发际线、头部比例和面部表情不变，只改变发型。
Keep the face shape, facial features, hairline, head proportions and facial expression unchanged; change only the hairstyle.
```

负面限制（按需挑，接在 prompt 末尾）：

```
不要改变脸型，不要改变五官，不要改变发际线，不要增加头发长度，不要出现塑料感发丝，不要出现油腻高光，不要出现发丝融化、重复、穿插或不自然的块状头发。
changed face shape, altered facial features, changed hairline, longer hair, plastic-looking hair, greasy highlights, melted / duplicated / intersecting strands, unnatural clumped hair
```

「不要出现油腻高光」只在想要哑光、干爽的时候加；角色本来就是油头、湿发感、发根出油的，删掉这条，改写成具体状态。九项写法适合短碎发、纹理烫、三七分、背头、法式卷、狼尾和中长发；女生发型也可以借这个顺序，第 6、7 项换成「两侧鬓发 / 发尾落在哪」。

**写法提醒**：发型对气质的影响往往比脸大，〔全〕距离也看得见，「一般」精细程度时发型要写足（名称 + 结构 + 颜色 + 状态）；「深入」或要做角色卡时，按上面九项写满。
