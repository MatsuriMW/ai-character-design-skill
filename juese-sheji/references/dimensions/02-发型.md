# 发型

可见距离：发型轮廓、长度、颜色〔全〕；刘海细节、纹理、发际处理〔中〕；发丝状态、头皮、发根颜色〔特〕。
网上很多叫法混用（比如鲻鱼头和狼尾常被当成一回事），锁定段里**一定带上英文名和结构描述**，别只写中文俗名。

## 发色、发质、状态

| 子项 | 写法 | 英文 | 距离 |
|---|---|---|---|
| 发色 | 纯黑 / 自然黑棕 / 冷棕 / 亚麻 / 灰金 / 漂白 / 挑染（写颜色和位置） / 内层挑染 / 发根长出 3cm 黑色 | jet black / natural dark brown / ash brown / flaxen / ash blonde / bleached / streaks / hidden underlayer color / 3 cm dark roots grown out | 〔全〕/〔特〕 |
| 白发 | 鬓角花白 / 头顶几根白发 / 全白 | greying temples / scattered grey hairs / fully white | 〔中〕 |
| 发质 | 细软 / 粗硬 / 毛躁 / 有光泽 | fine and soft / coarse and stiff / frizzy / glossy | 〔中〕 |
| 状态 | 湿发感（刚洗或抹了发蜡） / 蓬松 / 塌（贴头皮） / 油（发根结缕） / 睡乱了一侧压扁 / 被风吹乱 | wet-look / voluminous / flat against the scalp / greasy clumped roots / bedhead flattened on one side / wind-tousled | 〔中〕 |
| 打理痕迹 | 梳齿痕清楚 / 发胶定型硬 / 刘海挂一缕到眉尾 / 鬓角碎发 / 耳后别着一缕 | visible comb lines / stiff gel hold / one strand falling to the brow tail / loose wisps at the temples / tucked behind one ear | 〔中〕 |

**写法提醒**：发型对气质的影响往往比脸大，〔全〕距离也看得见，「一般」精细程度时发型要写足（名称 + 结构 + 颜色 + 状态）。
