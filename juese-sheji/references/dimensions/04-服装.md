# 服装

可见距离：品类、主色、剪影、版型〔全〕；领型、穿法、面料肌理、做旧〔中〕；缝线、纽扣材质、起球、污渍细节〔特〕。
面料基础词表、做旧四级、状态词见 `../design-principles.md` 第 4、7 节，这里只补「往下再切一层」的写法。

一件衣服写到这几项才算具体：**品类 + 款式细节 + 版型 + 面料（组织）+ 颜色（HEX）+ 穿法 + 新旧**。

## 面料组织与肌理（「这块布是什么表情」）

| 名称 | 英文 | 样子 |
|---|---|---|
| 平纹 | plain weave | 一上一下交织，表面平整 |
| 斜纹 | twill | 布面一道道斜向纹路，牛仔、卡其都是 |
| 人字纹 | herringbone | 斜纹一正一反交替，排成一列列「人」字 |
| 席纹 / 方平 | basket weave | 经纬成组交错，像编出来的竹席 |
| 千鸟格 | houndstooth | 犬牙状的小格 |
| 威尔士亲王格 | Glen check / Prince of Wales check | 大格里套小格 |
| 细条纹 / 粉笔条纹 | pinstripe / chalk stripe | 一细一模糊的竖条 |
| 灯芯绒 | corduroy | 竖向绒条，写宽条 / 细条 |
| 粗花呢 | tweed | 粗羊毛，表面杂色颗粒和毛感 |
| 泡泡纱 | seersucker | 一条平一条皱，夏天 |
| 罗纹 | rib knit | 竖向凸起的针织纹 |

## 穿法（比衣服本身更能说明人）

| 写法 | 英文 | 带出的感觉 |
|---|---|---|
| 衬衫解开最上面两 / 三颗扣子 | shirt unbuttoned to the second / third button | 两颗随意，三颗轻佻、张扬 |
| 衬衫扣到最上面一颗、不打领带 | buttoned all the way up, no tie | 拘谨或刻意的潮 |
| 下摆只塞进去一半（前塞后不塞） | half-tucked shirt (front tuck) | 精心的随意 |
| 袖子挽到小臂 / 挽到手肘以上 | sleeves rolled to the forearm / above the elbow | 干活、利落 |
| 西装外套披在肩上不穿袖子 | jacket draped over the shoulders | 派头、做作 |
| 外套搭在一边肩上，用一根手指勾着 | jacket slung over one shoulder, hooked on a finger | 潇洒、轻佻 |
| 领子立起来 | popped collar | 张扬、老派花花公子 |
| 领带拉松、领口扣子解开 | loosened tie, top button undone | 下班、疲惫、喝过酒 |
| 裤脚卷两道露出脚踝 | jeans cuffed twice, ankles showing | 日系、讲究 |
| 卫衣帽子罩在头上 | hood up | 防备、躲 |
| 大一号 / 小一号 | one size too big / too small | 借来的、发胖了、长个子了 |

## 做旧与磨损（写在哪、怎么旧）

做旧四级见 `../design-principles.md`。具体部位写法：

- 袖口起毛、起球；手肘磨薄发亮；领口洗松、发黄；腋下汗渍发黄
- 牛仔裤：膝盖发白、后袋钱包印、手机印、裤脚磨毛
- 皮衣：肩部和肘部褪色发白、皱褶处裂纹
- 西装：肩部被包带压出一道印、口袋被手撑得变形
- 鞋：鞋头磨白、后跟踩扁

例：一户穷苦人家 → 荷叶边洗得卷起、毛衣袖口起球、裤腿一块洗不掉的油渍、领口汗渍发黄。**一件衣服该旧在哪里、脏在哪里，本身就在讲故事。**
