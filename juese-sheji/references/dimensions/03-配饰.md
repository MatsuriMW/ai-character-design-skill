# 配饰

按三个轴写：**材质 × 款式 × 戴法**。「一条项链」只给了品类，模型给的就是一条随便的细链子；三个轴都写了，才是一件具体的东西。
可见距离：大件项链、帽子、包、眼镜〔全〕；戒指、手链、耳饰、手表〔中〕；细链、小吊坠、指甲上的东西〔特〕。

## 戴法轴（最能说明人的往往是这一轴）

| 戴法 | 写法 | 带出的感觉 |
|---|---|---|
| 叠戴 | 两三条不同长度的项链叠在一起 / 一只手戴 3–4 枚戒指 | 讲究、玩得开 |
| 只戴一件 | 全身唯一的一件饰品 | 克制、这件东西对他有意义 |
| 位置 | 戒指戴在食指 / 小指；耳钉只戴一边 | |
| 露出方式 | 项链从解开的衬衫领口里露出来 / 塞在衣服里只露链子 | 前者张扬、后者含蓄 |
| 状态 | 链子缠在一起 / 吊坠翻到背后 / 戒指松了往下滑 / 表带磨出白边 | 生活感、不在意 |
| 不合身份 | 很新很贵的表配洗旧的 T 恤 | 暴发、借来的、假货 |

## 例：轻佻的男性

- 选定：一颗黑珍珠单颗吊坠，穿在细做旧银链上，从解开三颗扣子的衬衫领口露出来 + 右手食指一枚做旧银图章戒、小指一枚素圈
- 备选：①巴洛克式粗锁链金项链（更张扬、更港风）②左耳一只银色小圈耳环，只戴一边（更痞、更年轻）③不戴项链，只戴一块金色细表带腕表（更像精明的销售）
