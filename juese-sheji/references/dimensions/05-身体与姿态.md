# 身体与姿态

可见距离：体型、身高比例、站姿、走路〔全〕；肩颈、手势、坐姿细节〔中〕；手指小动作、呼吸〔特〕。
静态的（体型、站姿、头部角度）可以进生图锁定段；动态的（走路、手势习惯、重心变化）放视频动作段和表演说明。

## 体型

| 子项 | 写法 | 英文 |
|---|---|---|
| 身高比例 | 写几头身：7 头身 / 8 头身；腿长比例 | 7.5-heads-tall proportions |
| 骨架 | 肩宽 / 窄肩 / 溜肩 / 骨架小 / 手大 / 手腕细 | broad shoulders / narrow / sloping shoulders / small frame / large hands / slim wrists |
| 体脂与肌肉 | 精瘦（看得见手背血管、小臂线条） / 健身体型（斜方肌隆起、胸厚） / 运动员体型 / 瘦弱 / 微胖 / 啤酒肚（四肢细肚子凸） / 壮胖（力量型） | lean with visible veins on the hands / gym-built with developed traps / athletic / frail / soft and slightly heavy / beer belly on thin limbs / heavyset and strong |

## 站

| 写法 | 英文 | 带出的感觉 |
|---|---|---|
| 重心放在一条腿上，另一条腿松着，胯微微歪 | weight shifted onto one leg, hip cocked | 松、随意、轻佻 |
| 两脚分开与肩同宽站定，胸挺 | feet planted shoulder-width, chest open | 强势、军人、自信 |
| 双手插裤兜 / 只插一只手 / 只把拇指挂在裤袋边 | both hands in pockets / one hand in pocket / thumbs hooked in front pockets | 一只手显轻佻；拇指挂兜显牛仔、显痞 |
| 双臂抱胸 | arms crossed | 防备、审视 |
| 靠墙、肩膀抵着墙 | leaning one shoulder against the wall | 等人、闲、看戏 |
| 含胸、圆肩、脖子往前探 | hunched, rounded shoulders, head jutting forward | 长期伏案、自卑、劳累 |
| 背挺直、下巴微收 | upright spine, chin slightly tucked | 有训练、舞者、军人 |
| 手背在身后 | hands clasped behind the back | 领导、长辈、视察 |

## 坐

| 写法 | 英文 | 带出的感觉 |
|---|---|---|
| 椅子上往后瘫，腿伸长、脚踝交叉 | slouched back, legs stretched out, ankles crossed | 放松、不在乎 |
| 跷二郎腿（膝上叠腿） / 四字腿（一只脚踝搭在另一膝盖上） | legs crossed at the knee / figure-four leg cross | 四字腿显占地盘、显强势 |
| 反跨坐椅子，手臂搭在椅背上 | straddling a chair backwards, arms on the backrest | 痞、轻佻、要谈事 |
| 只坐椅子前三分之一，背挺直，手放膝上 | perched on the front edge, back straight, hands on knees | 拘谨、求人 |
| 一只胳膊搭在旁边的椅背上 | one arm draped over the neighboring chair back | 占有、松 |
| 蹲（脚跟着地） | deep squat, heels down | 街头、农村、工地 |

## 走

| 写法 | 带出的感觉 |
|---|---|
| 步子慢、肩膀带着身体晃 | 晃荡、轻佻、混 |
| 步子快、身体前倾、看地面 | 赶时间、怕人、心事重 |
| 拖着脚走、鞋底蹭地 | 累、懒、老 |
| 外八字、肩膀打开 | 大大咧咧、强壮 |
| 走路时一直看自己在玻璃里的倒影 | 自恋 |

## 头与视线（静态可进锁定段）

| 写法 | 英文 | 带出的感觉 |
|---|---|---|
| 头微微侧歪 | head tilted slightly | 打量、轻佻、好奇 |
| 下巴微抬，从下往上看人（眼皮半垂） | chin raised, looking down the nose | 傲慢 |
| 下巴压低，从眉骨下面往上看 | chin down, looking up from under the brows | 威胁、诱惑 |
| 看人时先看嘴、再看眼睛 | | 轻佻、调情（动态，放表演说明） |

## 手（手势习惯，动态）

| 写法 | 带出的感觉 |
|---|---|
| 说话时转戒指 / 摸项链吊坠 | 轻佻、紧张或自我欣赏 |
| 用手指把刘海往后拨 | 在意形象 |
| 手指敲桌面 | 不耐烦 |
| 一根手指勾着外套挂在肩上 | 潇洒 |
| 搭别人肩膀、手停留得比正常久 | 越界、轻佻 |
| 抽烟夹在中指无名指之间 / 把烟别在耳朵上 | 老派、工地、街头 |
| 掰手指关节 | 紧张或挑衅 |
| 抠指甲边的倒刺 | 焦虑 |
| 说话时手一直不离手机 | |

**写法提醒**：视频动作段只挑 1–2 个最有代表性的习惯动作，多了模型做不完。
