# 说话方式

这一维度**只作文字参考**：给编剧写台词、给表演定调、给写人物小传用。不写进生图 / 生视频 prompt，也不是配音参数。
和其他维度一样，不写「说话轻浮」「语气温柔」这种形容词，写可以照着念的具体东西。

## 子项

| 子项 | 写法举例 |
|---|---|
| 语速 | 比常人慢半拍 / 快、句子之间不换气 / 平时慢，一激动就快 |
| 语调起伏 | 平，几乎没有起伏 / 句尾总往上扬，像在问 / 句尾往下压，像下结论 / 重音放在人名上 |
| 音色 | 低、带气声 / 烟嗓、有点沙 / 鼻音重 / 清亮偏高 / 嗓子有点哑，像刚睡醒 |
| 音量 | 压着声音，要别人凑近听 / 一开口整桌都听得见 |
| 停顿 | 关键词前停一下 / 一句话说一半就停，等对方接 / 几乎不停 |
| 尾音与语气词 | 爱拖长尾音（「好——呀」） / 爱加「嘛」「啦」「哈」 / 句尾带一声轻笑 |
| 口头禅 | 写具体的词：「你懂的」「怎么说呢」「宝贝」「行吧」「讲道理」「其实吧」 |
| 称呼习惯 | 叫人「美女」「宝贝」「老板」「亲爱的」 / 只叫全名 / 叫姓加「老师」 / 叫小名 |
| 句式 | 爱用反问 / 爱用祈使句（「你过来」） / 话说一半、留着让人猜 / 长句、从句多、像念稿 / 只回两三个字 |
| 用词 | 夹英文 / 方言词（写哪里的、哪几个词） / 行话（写行业） / 网络用语（写年份感） / 成语多 |
| 说话时的身体 | 说话时离人很近 / 说话不看人 / 边说边笑 / 说到自己就摸后脑勺 |
| 不说什么 | 从不说「对不起」 / 不提自己家里 / 被问到就转移话题 |

## 输出格式（写进「说话方式参考」那一段）

1. 上面子项挑 4–6 个最能说明这个人的写清楚。
2. 附 **3 句示例台词**：一句打招呼 / 搭话，一句被拒绝或被质问时，一句他自己的口头禅场景。台词只用来示范语气，剧本里有现成台词时以剧本为准。

## 例：轻佻的男性

- 语速：慢半拍，每句话像是有时间陪你耗
- 语调：句尾往上扬，正经话也说得像玩笑
- 音色：偏低、带一点气声，凑近说
- 称呼：见谁都叫「美女」，熟一点叫「宝贝」
- 口头禅：「急什么」「开个玩笑嘛」
- 句式：爱用反问；被认真质问时不正面回答，笑着把话题绕开
- 示例：
  - 「美女，一个人？这么巧，我也一个人。」
  - 「生气啦？开个玩笑嘛，这么认真干什么。」
  - 「急什么，你看，我这不是来了吗。」
