## 表情谱与防夸张

表情谱（默认表情 + 六个基础情绪 + 专属表情）用 `07-微表情.md` 的肌肉写法，按 `../expression-restraint.md` 标强度、写不动的部位。模型会把表情做大，这份补丁专门防这个。

## 刚柔光谱

各维度之间统不统一、反差落在哪，用 `../soft-hard-axis.md` 看：每个部位都能放到刚（硬、直线、棱角、往外占）↔ 柔（软、曲线、圆钝、往里收）的光谱上，分底色（身份层）、推向（造型层）、习惯三层。「柔和」「硬朗」「温润」这些词在那里拆成名词。

## 可见距离

〔全〕全景就看得见 ·〔中〕中景（腰部以上）看得见 ·〔特〕特写才看得见。
精细程度「一般」写〔全〕〔中〕；「深入」三层都写。详见 `../articulate-rules.md` 第 6 节。

## 气质词 → 常用切口

同一个气质词，最常落在哪几个维度上。这是起点，不是标准答案：每个人还要加上他自己的处境、生活痕迹和不完美。

### 轻佻的男性（完整示例见 `../../examples/轻佻的男性.md`）

| 维度 | 切口 |
|---|---|
| 发型 | 中分帘发 / 侧分油头 / 刘海挂一缕到眉尾；湿发感 |
| 眼 | 桃花眼或眼梢微下垂；下眼睑微收（看人像在打量） |
| 嘴 | 嘴角天生微翘；单侧嘴角上提 |
| 配饰 | 珍珠单颗吊坠、做旧银叠戒、一边耳环；戴法比款式重要：从解开的领口露出来 |
| 服装 | 古巴领 / 花衬衫解开三颗扣子；外套用一根手指勾着挂在肩上；裤子偏贴身 |
| 姿态 | 重心在一条腿上，胯歪；一只手插兜；头微歪 |
| 手势 | 说话时转戒指、拨刘海；搭肩停留得比正常久 |
| 说话 | 慢半拍、尾音上扬、叫人「美女」「宝贝」、正经话也说成玩笑 |

### 清冷的女性

| 维度 | 切口 |
|---|---|
| 发型 | 黑长直 / 低马尾，没有碎发；或利落的锁骨发 |
| 脸 | 冷白皮；眉毛平而细；眼梢平或微上扬；薄唇、嘴角天生平 |
| 配饰 | 极少：一对小银耳钉 / 一块细表带的小表；或完全不戴 |
| 服装 | 高领细针织、一字领、灰白黑低饱和；版型利落不贴身；面料细腻无图案 |
| 姿态 | 背直、下巴微收；手放得很规矩；走路不晃 |
| 微表情 | 默认表情几乎不动；笑只有嘴角、眼睛不动 |
| 说话 | 句子短、尾音往下压、停顿多、很少用语气词 |

### 苦命的中年男人

| 维度 | 切口 |
|---|---|
| 脸 | 眉骨前凸、脸颊凹陷；肤色不均整体蜡黄；法令纹和抬头纹深 |
| 生活痕迹 | 掌心和虎口厚茧、指甲缝发黑；脸和脖子晒得粗黑；额角一道没长好的伤口 |
| 发型 | 寸头长出一截没去剪；鬓角花白；头顶被安全帽压扁 |
| 服装 | 洗旧发灰的夹克、袖口起毛；裤子膝盖发白；鞋头磨白、鞋跟踩扁 |
| 姿态 | 圆肩、脖子往前缩；蹲着抽烟 |
| 说话 | 话少、慢、常常说一半；口头禅「没事」「都一样」 |

### 精明的销售 / 中介

| 维度 | 切口 |
|---|---|
| 发型 | 侧分油头、梳齿痕清楚；或短而规整的渐变 |
| 配饰 | 钢带表（偏大）、皮带方扣；手机不离手 |
| 服装 | 西装偏紧、袖子偏短露出衬衫；皮鞋擦得很亮但鞋跟磨偏 |
| 姿态 | 身体前倾、点头频率高；递东西用双手 |
| 微表情 | 礼貌笑：嘴角提、眼周不动 |
| 说话 | 语速快、叫人「哥」「姐」「老板」；爱说「我跟您交个底」 |

### 健身教练

| 维度 | 切口 |
|---|---|
| 身体 | 斜方肌和三角肌把 T 恤肩线撑满；小臂血管明显；脸颊脂肪少、下颌线清楚 |
| 生活痕迹 | 掌心指根一排茧；手腕缠过护腕的白印 |
| 服装 | 紧身短袖、运动短裤；运动鞋鞋底磨平 |
| 姿态 | 背挺、肩打开；站着时手习惯性叉腰 |
| 说话 | 嗓门大、节奏感强；口头禅「再来一组」「核心收紧」 |

### 温柔的大块头（完整示例见 `../../examples/温柔的大块头.md`）

刚底色 + 柔造型 + 往里收的习惯，见 `../soft-hard-axis.md` 第 5 节。

| 维度 | 切口 |
|---|---|
| 体型 | 骨架大、肩宽、斜方肌隆起、手大指节粗（底色刚，不改） |
| 脸 | 方脸但脸颊有肉；眉毛粗但眉尾往下；眼梢微垂、黑眼珠大、有卧蚕 |
| 发型 | 寸头长出一截、头顶圆、两侧不铲青 |
| 服装 | 落肩粗针织开衫、圆领旧棉 T、洗软的灯芯绒；燕麦、奶咖、雾蓝，低对比 |
| 配饰 | 几乎不戴；有也是软的：一根编织绳、布表带 |
| 姿态 | 含胸、肩往里收；和人说话先蹲下或弯腰；手放身前 |
| 说话 | 声音低、语速慢、先问「你没事吧」 |
