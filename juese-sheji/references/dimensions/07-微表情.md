# 微表情

可见距离：几乎都是〔特〕，个别（大笑、皱眉）〔中〕。「一般」精细程度下只写一个**静态的默认表情**（平时脸上挂着什么），不写变化。

三条规矩（见 `../articulate-rules.md` 第 4 节）：
1. **写肌肉动作，不写情绪词。**
2. **写幅度和时长**：微微 / 明显；不到一秒 / 停两秒才落回去。
3. **一个镜头只写一处变化。**

下表按 Ekman & Friesen 的面部动作编码系统（FACS）整理，AU 是动作单元编号，方便查证和跨模型复用（编号为常用版本，要打字幕时按 FACS 手册核一遍）。

## 常见组合（写给模型的是右边，不是左边的情绪名）

| 你想表达的 | 写法（肌肉动作 + 幅度 + 时长） |
|---|---|
| 真笑 | 嘴角上提，同时苹果肌推高、眼角挤出鱼尾纹（AU6 + AU12） |
| 假笑 / 礼貌笑 | 嘴角上提，眼周不动、眼睛没有眯（只有 AU12） |
| 不屑 / 轻蔑 / 坏笑 | 一侧嘴角微微上提，不到一秒就落回去，眼睛不动（单侧 AU12 / AU14） |
| 轻佻的打量 | 下眼睑微微收紧，视线从对方的嘴慢慢移到眼睛，一侧嘴角浅浅提起（AU7 + 单侧 AU12，视线动作写进同一句） |
| 委屈、强忍 | 眉毛内侧微微上抬，嘴唇抿紧，下巴轻轻发抖（AU1 + AU24 + AU17） |
| 难过 | 眉头内侧上抬、嘴角往下压（AU1 + AU4 + AU15） |
| 生气、压着火 | 眉头下压聚拢，嘴唇压紧变薄，下颌咬紧、咬肌鼓起（AU4 + AU23/24） |
| 厌恶 | 鼻梁皱起、上唇往上掀（AU9 + AU10） |
| 惊讶 | 眉毛整体上抬、眼睛睁大、嘴唇分开（AU1 + AU2 + AU5 + AU26） |
| 害怕 | 眉毛上抬且聚拢、眼睛睁大、嘴唇横拉（AU1 + AU2 + AU4 + AU5 + AU20） |
| 紧张 | 喉结上下动一次 / 舔一下嘴唇 / 眨眼变快 |

## 幅度与时长的写法

- 幅度：几乎看不出（barely） / 微微（slightly） / 明显（clearly） / 用力（forcefully）
- 时长：一闪而过（a flicker, under half a second） / 不到一秒就落回去（holds for less than a second, then relaxes） / 停两秒（holds for two seconds）
- 顺序：先……再……（眼睛先动，头后动）
- 例：「His left mouth corner lifts slightly and drops back within a second; his eyes stay still.」

## 静态默认表情（生图锁定段可写）

不说话、不做事时脸上挂着的样子：

| 写法 | 英文 |
|---|---|
| 嘴角天生微微上翘，像随时要笑 | resting mouth corners slightly upturned |
| 眼睛半睁、眼皮有点沉 | heavy-lidded resting gaze |
| 眉间一道浅浅的竖纹，不皱眉也在 | a faint permanent vertical line between the brows |
| 嘴微微张着 | lips slightly parted at rest |
| 下颌一直咬着 | jaw set at rest |

**写法提醒**：普通商用模型的表情普遍偏夸张，宁可写小一号（「微微」），再加时长上限。
