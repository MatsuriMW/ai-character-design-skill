# 创意风暴方法库

每个方向用**一种**方法起手，保证方向之间真的不同。方法可以组合，但别一个方向里塞五种。

## 起手方法

| 方法 | 怎么想 | 例子（思路示意，不是现成答案） |
|---|---|---|
| **反差** | 让衣服和性格 / 处境故意反着来，反差本身就是信息 | 内向的人穿一件很亮的外套——是别人送的；落魄的人坚持每天熨衬衫 |
| **物件叙事** | 让一个小东西背负整个故事，随剧情变化 | 一只挂件、一块旧表、一把伞；它出现、磨损、丢失、被找回 |
| **时间痕迹** | 用身体和衣物的变化代替字幕表达时间 | 胡子、指甲、头发油度、衣服越来越皱、鞋越来越脏 |
| **色彩隐喻** | 给角色一个专属颜色，让它承担意义并在关键时刻变化 | 全片只有她有红色；最后一场红色消失 |
| **母题呼应** | 让服化道和全片的视觉母题押韵 | 片子的母题是玻璃和倒影——角色戴眼镜、穿反光面料 |
| **职业细节放大** | 找到职业带来的一个真实、具体、少见的细节 | 保洁员的袖套、厨师手上的烫痕、程序员磨亮的手腕处 |
| **不合身** | 衣服不合身说明它不是为他买的，或者他变了 | 父亲的西装、瘦下来后松掉的裤腰、借来的鞋 |
| **时代符号** | 挑一个那一年最有辨识度的物件，用得克制 | 某一年流行的发型、手机挂绳、校服外套 |
| **层次与暴露** | 用叠穿和露出的部分讲「表面 / 里面」 | 体面的外套底下是起球的毛衣，只在脱外套那一场露出来 |
| **减法** | 全身几乎没有信息，只留一个点 | 一身灰，只有一个鲜艳的发夹 |
| **借来的身份** | 角色在扮演别人，衣服是面具 | 面试时穿的不属于自己的风格，回家第一件事是换掉 |
| **原型借用 / 翻转** | 从 `archetypes/索引.md` 拿一个观众熟悉的原型，只借它的剪影或姿态，再在一处反着来 | 被忽视的郊区妻子的开衫 + 抱胸，放在一个其实掌控全家的人身上 |
| **群体与例外** | 先设计人群的统一，再让主角在一个地方不统一 | 所有人都穿深色，主角的伞是黄色的 |

## 发散时的检查

- 4–6 个方向里，**至少一个**是第一直觉的反面。
- 方向之间要在**概念**上不同，不是同一个概念的配色变体。
- 每个方向都要有**标志性单品**，而且能说出它在剧情里怎么被用到。
- 每个方向都要过一遍「真」：大胆可以，但不能穿帮。大胆方向如果有年代风险，写进风险栏。

## 收敛打分

| 方向 | 真（1–5） | 准（1–5） | 记得住（1–5） | AI 好生成（1–5） | 一句话评价 |
|---|---|---|---|---|---|

推荐时不一定选总分最高的：可以把 A 方向的主造型和 C 方向的标志性单品组合起来，说清楚为什么。

## 给配角和道具的「小而准」

- 一个配角只需要**一个**细节就能立住（保洁阿姨的袖套、服务员手背上的创可贴）。
- 道具点子优先找**会变化的**东西：能被用掉、弄坏、丢掉、送出去的东西，比静止的摆设更有戏。
- 陈设道具从「这个空间的主人缺什么」想，比从「这里应该有什么」想更有人物。
