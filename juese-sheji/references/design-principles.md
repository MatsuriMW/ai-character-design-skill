# 服化道设计原则与词表

按需读：设计服装读 1–4，妆发读 5，道具读 6，查词读 7。

## 1. 服装先讲人物

一套衣服回答三个问题，答案要能在画面里**看出来**：

| 问题 | 看得见的信号 |
|---|---|
| 这个人挣多少、在什么环境里工作 | 面料（化纤 / 棉 / 羊毛）、合身程度（买现成的 / 改过的 / 定制）、新旧、品类（冲锋衣、卫衣、衬衫、西装） |
| 这个人在乎什么 | 哪一处特别讲究（鞋擦得很亮、手表、熨过的领子），哪一处将就 |
| 这个人今天 / 这段时间怎么样 | 皱、脏、扣错、领口歪、穿了昨天那件、季节不对 |

反例：都市白领加班到凌晨，衬衫依然笔挺如新——这是广告，不是人物。

## 2. 剪影先于细节

AI 短片里人物常常很小（人占画面 30%，大量空间）。远景时观众只能认出**剪影和色块**，所以：
- 每个主要角色要有一眼能认出的轮廓：长外套 / 短夹克、宽 / 窄、帽子、包的位置。
- 同一场里两个角色的剪影和主色要拉开，否则远景分不清谁是谁。
- 细节（扣子、纹理）只在近景和特写里起作用，锁定段要写，但设计时别指望靠它区分人物。

## 3. 色彩关系

服装颜色永远相对于**场景**来定：
- **融入**：服装和环境同色系 → 人被空间吞掉，适合孤独、被淹没、日常循环。
- **跳出**：只给一个元素高饱和（红围巾、黄雨衣）→ 视线锚点，适合「这个人不一样了」的时刻。跳出色全片最好只有一种，用得越少越有力。
- **变化**：同一角色随弧光改变主色明度或饱和度（从灰到更灰，或者最后一场忽然穿了亮色）。

写颜色一律给 HEX，再加一个普通人能懂的名字（`#3B4A5A 灰藏青`）。避免纯黑 `#000000` 和纯白 `#FFFFFF`：生图模型会把纯黑压成没有细节的色块，纯白会过曝。用 `#1E1E22`、`#F2EFE8` 这样的近黑近白。

## 4. 材质与做旧

材质决定光怎么落在衣服上，是写实感的主要来源：

| 材质 | 画面特征 | 适合 |
|---|---|---|
| 化纤（聚酯、尼龙） | 平、反光硬、褶皱尖 | 快时尚、工作服、冲锋衣 |
| 棉（牛津纺、帆布、斜纹） | 哑光、褶皱软、洗旧后发白 | 日常、工装 |
| 羊毛（精纺、粗花呢、针织） | 绒感、吸光、边缘柔 | 秋冬、讲究、学院 |
| 牛仔 | 靛蓝、磨白、猫须 | 工装、复古 |
| 皮革 / 麂皮 | 皮革有高光，麂皮吸光无高光 | 外套、鞋、包 |
| 灯芯绒 | 条纹在光下明暗交替 | 复古、学院 |

做旧分四级，写进造型卡：
- **0 新**：刚买，折痕都在（很少用，除非剧情要「新」）
- **1 穿过**：自然褶皱，最常用
- **2 旧**：领口袖口起毛、膝盖鼓包、颜色洗淡
- **3 破**：磨破、污渍、开线（要有剧情理由）

## 5. 妆发

按**状态**设计，不按场次。一个角色通常 2–4 个状态就够。

| 项 | 写法（要可量化） |
|---|---|
| 发型 | 长度（cm）、分线位置、整齐度（刚洗 / 一天 / 三天没洗、油、塌、翘） |
| 胡子 | 无 / 胡茬约 1mm / 3mm / 短须 / 留须；分布（下颌、上唇、连鬓） |
| 眼周 | 黑眼圈：无 / 浅 / 明显发青；眼袋；血丝 |
| 肤色肤质 | 底色 HEX；油光（T 区）、干燥起皮、苍白、熬夜的灰黄、晒红 |
| 唇 | 颜色、干裂 |
| 特效妆 | 伤口的位置、大小、愈合阶段（新鲜 / 结痂 / 疤）；汗、泪痕、灰尘 |
| 手 | 指甲长度、干净程度、倒刺、戒指 |

时间流逝最便宜的表达：胡子长度、指甲长度、头发油度、黑眼圈。连戏表里给它们每个时间点的值。

## 6. 道具

| 类别 | 定义 | 要做到什么程度 |
|---|---|---|
| **重点道具 hero prop** | 剧情要用、要特写、或者会变化 | 每个一张卡：规格、数量、状态变化、锁定段 |
| **手持道具 hand prop** | 角色随手拿、随身带（手机、包、钥匙、杯子） | 进总表；同一角色全片用同一个，除非剧情换 |
| **陈设道具 set dressing** | 摆在场景里，说明这是谁的空间 | 按场景列「必须有 / 可选 / 不能有」 |
| **消耗道具** | 戏里会被吃掉、撕掉、打碎的 | 写清每个镜头前后的状态 |

道具设计的三个检查：
- **它是谁的？** 杯子上的磕痕、手机壳、包上挂的东西，都是人物信息。
- **它会不会抢戏？** 陈设里出现可读文字、鲜艳色块、认识的品牌，会把视线拉走。
- **时代对不对？** 手机型号、支付方式、交通卡 / 健康码、电脑和显示器样式、包装设计。

AI 生成的道具最容易出错的：手里拿的东西（手指和物体穿插）、数量（「三个杯子」变成四个）、文字（乱码）、对称物（筷子、耳机）。重点道具尽量让它在画面里**简单、大、少**。
