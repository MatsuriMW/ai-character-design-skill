# 漂移检查清单（审出图用）

拿到生成的图 / 视频后，对照人物精细描述逐项看：哪些写了的东西被模型「改回了平均值」。
**这份清单只用来审结果，不写进 prompt**：否定指令（「不要磨皮」）效果差，修的办法是把对应的那一行写得更具体、或者加参考图（见每条的「怎么修」）。

用法：每张图逐项打 ✓（保住了）/ ✗（漂了）/ —（这个镜头看不见）。✗ 的项记下来：同一项在同一个模型上反复漂，写进 `model-notes.md`。

## 1. 身份锚点（最严重，漂了就不是同一个人）

| 漂移 | 看什么 | 怎么修 |
|---|---|---|
| AI 平均脸 | 皮肤像磨过皮、没有毛孔；五官左右完全对称；每个部位都在「标准」位置 | 加不完美（痣写到具体位置、胡青、纹路）；脸部写结构而不是「好看」；换写实向模型或加参考图 |
| CG 雕塑脸 | 高鼻梁、深眼窝、锋利下颌、眉骨、颧骨全部拉满，像游戏建模；男性角色最常见，加了胡茬反而更假 | 骨相只留 1–2 个主要特征，其余写普通，加一处不对称（`dimensions/01-脸与五官.md`「骨相别全拉满」）；删掉 chiseled / razor-sharp 这类词；定妆照、角色卡用大面积柔光（主光在镜头前方略高、略偏一侧），强侧光和高对比会把骨相再放大一档 |
| 贴图胡茬 / 材质贴图皮肤 | 胡茬是均匀的黑色噪点、边界整齐，像贴上去的；毛孔、痘印、泛红铺满整张脸 | 胡茬写疏密和方向（上唇、下巴密，脸颊上方稀）；瑕疵写局部位置和处数（鼻子和内侧脸颊的毛孔、零散几颗痘印） |
| 头盔头发 / 复制眉毛 | 头发是一整块光滑色块、发际线一刀齐；两边眉毛一模一样、像画上去的色块 | 加「发际与碎发」一项（`dimensions/02-发型.md`）；眉毛写单根毛流和两侧浓淡差 |
| 脸型 / 骨相变了 | 窄长脸变成鹅蛋脸、颧骨 / 下颌变柔和 | 骨相那一行写更硬的结构词（颧弓外扩、下颌角方而外扩）；加正脸参考图 |
| 被拉回性别平均脸 | 刚端的女性下颌变尖、肩变窄、眼睛变大变圆；柔端的男性下颌变方、眉压眼；温柔的大块头脸也被画硬 | 按 `soft-hard-axis.md` 第 9 节：刚端女性写颧弓、下颌角、肩宽的结构名词并写出垫肩；柔端男性写脸颊脂肪、圆钝下颌和眼的温润感五项；脸和体型分两句写；加正脸参考图 |
| 眼型漂 | 内双 / 单眼皮变成平行双；眼梢下垂变成上扬；桃花眼变成大圆眼 | 眼皮写成名词（hooded inner double lid）；眼梢写方向；特写镜头拼特写细节 |
| 年龄漂 | 变年轻（最常见）或变老；纹路消失 | 年龄写数字 + 写纹路的位置和深浅；老人写老年斑、颈纹 |
| 体型漂 | 瘦子变匀称、胖子变瘦、啤酒肚消失、肩宽变了 | 写几头身、肩宽、腰腹；全景镜头要单独确认 |
| 永久特征丢失 | 痣、疤、饺子耳、断眉、缺的牙不见了 | 写位置（左眼下方 / 右眉尾）；这类特征只在近景以上才稳，全景丢了不算漂 |
| 肤色漂 | 晒黑的人变白、蜡黄变红润 | 写成具体的颜色词（deep sun-tanned / sallow），必要时加 HEX |

## 2. 造型（这一场该是这一套）

| 漂移 | 看什么 | 怎么修 |
|---|---|---|
| 发型回到默认 | 中分帘发变成普通短发、背头变成侧分、湿发感变蓬松 | 发型写名称 + 英文 + 结构 + 状态，四样都写；还漂就按 `dimensions/02-发型.md` 的九项顺序写满，换发型时加「保持脸型、五官、发际线不变，只改变发型」 |
| 衣服变新 | 做旧、褶皱、起球、污渍消失，像刚剪吊牌 | 做旧写到部位（手肘磨亮、领口发黄）；状态词放在单品后面紧挨着 |
| 穿法丢失 | 解到第三颗扣子变成扣好；半塞变全塞；挽起的袖子放下来 | 穿法单独写一句，不要埋在长句中间 |
| 配饰丢失 / 换材质 | 黑珍珠变白珍珠、做旧银变亮金、戒指数量变、换手 | 材质 × 款式 × 戴法都写；写清哪只手哪根手指 |
| 颜色漂 | 主色偏了、花色变了 | 主色写 HEX；图案写成名词（small off-white floral print） |
| 出现 logo / 文字 | 衣服、包、鞋上冒出品牌标志或乱码字 | 款式描述代替品牌名；写清「plain, unbranded」作为正向描述 |
| 季节 / 场合不对 | 冬天的戏穿短袖、正式场合穿拖鞋 | 回去看连戏表（模式 C） |

## 3. 状态（随剧情变的）

| 漂移 | 看什么 | 怎么修 |
|---|---|---|
| 状态没跟上 | 上一镜淋湿了这一镜是干的；伤口位置换边；包扎消失 | 状态写进本镜 prompt，写清位置和程度 |
| 精神状态没跟上 | 写了熬一周，出图气色红润、头发蓬松；或者轻档画成了重档 | 按 `dimensions/09-精神状态.md` 写落点（眼周、气色、头发、衣服打理、姿态），不写状态名；想要中档就写轻档的项再加一两项 |
| 状态带错了 | 不该有的伤 / 脏出现在上一场之前 | 检查拼 prompt 时是不是拼错了 Look |

## 4. 动作与表情（视频）

| 漂移 | 看什么 | 怎么修 |
|---|---|---|
| 表情夸张 | 「微微一笑」变成咧嘴大笑；委屈变成大哭；露两排牙、O 形嘴、挂眼泪、全脸同时动、左右完全对称、像表情包 | 按 `expression-restraint.md` 第 6 节的顺序修：降一级强度、补不动的部位、删情绪名、换写实影像语境、用默认脸参考图只改一处 |
| 做表情时换了脸 | 表情板里每一格像不同的人；一笑下颌变尖、眼睛变大 | 表情越大越容易漂：先降强度；每格带同一段主设定；格子减到 6 个或拆成单格；用默认脸参考图编辑 |
| 表情和这个人对不上 | 压着的人笑出两排牙；冷的人表情丰富 | 回表情谱看「表达方式」的强度上限 |
| 习惯动作丢失 | 转戒指、拨刘海没出现 | 动作写成具体的手和物件（thumb turns the signet ring） |
| 多处变化互相打架 | 同时写了眼神、嘴角、手势，结果都做过头 | 删到只剩一处 |
| 动作做不完 | 后半段动作糊掉 | 一个镜头不超过 3–4 个动作节点 |

## 5. 生成质量（不是设计问题，但要记下）

- 手指数量、手和物件的穿插
- 多人同框时两个人的脸 / 衣服互相串：A 的颜色、发型、标志性单品跑到 B 身上，两个人的脸越来越像。修法见 `ensemble.md`：先确认两人在剪影和主色上已经拉开，prompt 按位置一人一段写、每人先写最能区分他的 2–3 项，有参考图每人一张；还是串就拆成单人镜头 + 关系镜头
- 远景人物脸部崩坏（全景本来就该只写主设定）

## 审完写什么

每张图一行：`镜头 / 模型 / ✗ 的项 / 怎么修`。同一模型上反复 ✗ 的项（比如某模型总把内双改成平行双、总把做旧洗掉），整理进 `model-notes.md`，下次给这个模型写 prompt 时提前加强那一行。
