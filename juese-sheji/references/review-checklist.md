# 检验清单与打分标准

六个维度，每个 1–5 分。逐条问下去，问题写进报告时都要带**证据**（剧本哪一场、造型卡哪一行、参考图哪个位置、查到的资料出处）。

## 1. 时代与环境（真）

| 检查点 | 要问的问题 | 常见翻车 |
|---|---|---|
| 年份 | 这个款式、面料、品类在那一年是否已经出现？是否已经过时？是不是那几年的流行而不是现在的流行？ | 用当下的版型（落肩、阔腿、机能风）去穿十几年前的戏 |
| 地点与气候 | 那个城市那个季节的温度、雨水，人会穿几层？南北差异、城乡差异？ | 南方梅雨天穿厚羽绒；北方冬天室外只穿一件夹克 |
| 阶层与价格带 | 以角色的收入，买得起吗？会去哪买（商场 / 网购 / 批发市场 / 别人给的）？ | 刚工作的年轻人一身高价单品；县城角色穿一线城市的买手店风 |
| 职业与场合 | 上班有没有着装要求？这个场合（葬礼、面试、通宵加班、医院）会怎么穿？ | 工地上穿白球鞋；葬礼上穿亮色 |
| 时代物件 | 手机、支付方式、交通卡 / 码、包装、电器、招牌字体、发型潮流 | 2010 年的戏出现全面屏手机；疫情戏没人戴口罩，或者口罩款式不对 |
| 社会环境 | 那段时间的社会氛围会不会体现在穿着上（疫情、经济好坏、运动会、某个流行事件）？ | 完全真空，看不出是哪一年 |

**查证方法**：不确定的点先列出来，联网查当年的新闻图片、街拍、电商商品存档、老照片论坛；查到的写出处，查不到的标「需查证」。宁可标不确定，也不要凭印象下结论。

打分：5 = 挑不出穿帮，还有一两处很准的年代细节；3 = 没有明显穿帮但看不出年代；1 = 有穿帮。

## 2. 身份与处境（真）

- 只看衣服，能猜出这个人大概做什么、挣多少、住哪里吗？
- 新旧程度对吗？日常衣服是穿过、洗过、有褶皱的，不是刚拆吊牌。
- 有没有「广告感」：太整齐、太干净、太好看，像在拍服装目录？
- 衣服是谁买的？自己挑的、家人买的、公司发的、二手的，会决定它合不合身、搭不搭。

打分：5 = 一眼能读出身份和处境；3 = 能读出大概，但细节像「通用都市青年」；1 = 和身份矛盾。

## 3. 性格与弧光（准）

- 这身衣服在替**哪个形容词**说话？和人物小传里的性格对得上吗？（讲究 / 将就 / 防御 / 炫耀 / 讨好 / 想被看见 / 想消失）
- 有没有一个「讲究的地方」和一个「将就的地方」？两者之间的反差往往就是性格。
- 弧光：第一场和最后一场的服化道有区别吗？区别是剧情给的理由吗（换工作、失去某人、决定改变）？变化的方向和角色的变化一致吗？
- 主角和配角：主角的造型是不是全片最有「信息量」的？配角有没有抢走主角的视线？
- 有没有和角色性格**刻意的反差**？如果有，是设计出来的还是没想清楚？

打分：5 = 不看台词也能读出性格，弧光清楚；3 = 性格大致对，但服化道全片不变或者变得没有理由；1 = 读出来的性格和剧本相反。

## 4. 记忆点（记得住）

- **一句话测试**：观众能不能说出「就是那个穿 / 拿 / 戴 X 的人」？说不出来就是没有记忆点。
- **标志性单品**：有没有一件观众会记住的东西（一件外套、一个配饰、一个道具、一个发型）？它有没有在剧情里被用到（被弄脏、被送人、丢了、换掉）？
- **剪影**：远景只看轮廓，能认出是他吗？和同场其他角色的剪影拉得开吗？
- **群像**：多个主要角色时，按 `ensemble.md` 的七个轴两两比较：剪影或主色撞了、或者超过 3 个轴相同，就算没拉开；转成黑白还能不能分清；有没有两个主要角色挤在同一个视觉领地。
- **颜色锚点**：主角有没有一个属于自己的颜色？全片这个颜色有没有被别人滥用？
- **重复与变奏**：标志性元素有没有重复出现，并且在关键时刻发生变化（这一次它不见了 / 破了 / 换了颜色）？
- 记忆点是不是**为角色服务**？只是好看、和角色没关系的记忆点要扣分。

打分：5 = 有标志性单品，且参与了叙事；3 = 好看但记不住，或者记得住但和角色无关；1 = 完全淹没。

## 5. 画面与可生成性

- 和场景色调是什么关系（融入 / 跳出 / 变化）？是不是有意的？
- 有没有呼应全片的视觉母题（某种光、某个颜色、某个形状）？
- 锁定段：每个部位都写了吗？颜色有 HEX 吗？有没有形容词？有没有写「无 logo、无文字」？
- 有没有 AI 很难稳定生成的东西（复杂图案、可读文字、细小且对称的配饰、手持复杂道具）？能不能简化？

打分：5 = 和画面有设计关系，锁定段可以直接用；3 = 不冲突但没有设计；1 = 和场景打架，或者锁定段写不出来。

## 6. 具体化程度（写给模型的够不够具体）

- **形容词残留**：造型描述、锁定段里还有没有「帅气」「高级感」「轻佻」「有质感」这类伞形词（清单见 `articulate-rules.md` 第 1 节）。每个都要指出能换成哪个名词或动作（发型名、款式名、材质、穿法、肌肉动作）。
- **判断词**：有没有「贼眉鼠眼」「一脸苦相」「油腻」这种带道德判断或情绪结论的词，会把模型拉回刻板印象。改成形态描述（第 3 节）。
- **平均脸风险**：脸部有没有至少 2 处不完美；全是「标准」「精致」「好看」的五官就会出 AI 平均脸。
- **痕迹对不对得上**（`dimensions/06-生活痕迹.md`）：职业、经历、阶层该留下的印子有没有写（体力劳动者的手、拳手的耳朵、常年户外的晒痕）；写了的和人物是否一致（健身教练有啤酒肚、常年户外却冷白皮、说是农民手却白净 = 穿帮）。
- **精细程度对不对**：全景镜头里写了一堆〔特〕的细节（看不见，还挤掉主设定）；或者特写镜头只有主设定、缺特写细节。
- 打分：5 = 每个维度都是名词或动作，有不完美和痕迹；3 = 主要维度具体，但还剩几个伞形词；1 = 基本是形容词堆砌。

## 严重度

| 级别 | 定义 | 例 |
|---|---|---|
| 🔴 必须改 | 穿帮，或者读出来的角色和剧本相反 | 2015 年的戏里有 2020 年才普及的东西 |
| 🟠 建议改 | 角色读得不准，或者没有记忆点 | 主角和路人穿得一样，远景认不出 |
| 🟡 可以更好 | 能用，但有更好的选择 | 标志性单品有了，但剧情里没用到它 |
| ⚪ 生成风险 | AI 层面的问题 | 锁定段漏了鞋 |

## 总结论

- **通过**：五项都 ≥ 4，没有 🔴。
- **小改后通过**：没有 🔴，或者 🔴 只有一两处、改一件就能解决。
- **重新发散**：「性格与弧光」或「记忆点」≤ 2，说明方向本身有问题，转模式 B。
