# 慎用原型

下面这些是影视里有名的套路，但它们的「好认」来自对一个群体的偏见。认识它们是为了**避开**，或者在要用的时候把它重写成一个真正的人。

检验模式（模式 A）里，看到这些要标出来。

| 原型 | 是什么 | 问题 | 要用就这样改 |
|---|---|---|---|
| **魔法黑人** | 一个黑人角色出现，只为帮助白人主角成长，自己没有故事 | 把一个群体当工具 | 给他自己的目标、欲望和结局 |
| **龙女 / 莲花女** | 亚洲女人要么是危险的诱惑者（旗袍、红唇、长指甲），要么是温顺牺牲的恋人 | 把亚洲女性性感化、符号化 | 让她的服装来自她的职业和处境，不是来自异域想象 |
| **傅满洲 / 黄祸** | 留长指甲、长胡子、阴险的东方反派 | 种族妖魔化 | 别用 |
| **白人救世主** | 白人主角来到「落后地区」拯救当地人 | 当地人没有主体性 | 让当地人自己解决问题 |
| **先死的黑人** | 恐怖片里黑人角色第一个死 | 一次性角色 | 别让他第一个死，或者让他活到最后 |
| **埋葬同性恋** | 同性恋角色总是死去或悲剧收场 | 让一个群体只有悲剧 | 给他们一个好的结局 |
| **娘炮好闺蜜** | 女主身边的男同性恋朋友，只负责购物和毒舌 | 把人简化成配件 | 给他自己的感情线 |
| **疯狂前任** | 女人分手后就疯了 | 女性情绪被病态化 | 给她的情绪一个合理的来源 |
| **阿拉伯恐怖分子** | 中东男人 = 头巾 + 胡子 + 恐怖分子 | 种族刻板 | 别用 |
| **野蛮的原住民** | 羽毛、战纹、野蛮 | 文化扭曲 | 别用；需要时按真实文化考据 |
| **地域黑** | 某地人 = 骗子 / 土 / 小气（包括中国国内的地域梗） | 地域歧视 | 喜剧可以用口音和习惯，但别把一个地方的人都写成坏人 |
| **残障即反派** | 疤痕、残缺 = 邪恶 | 把身体差异和恶联系起来 | 反派的恶来自选择，不来自外貌 |

## 用原型时的通用原则

1. **原型可以有，群体不能被等同于原型。** 一个金发妻子是忧郁的，不等于所有金发女人都忧郁；但如果全片唯一的少数族裔角色是罪犯，那就是问题。
2. **看全片的人物分布**：谁有名字，谁有台词，谁有结局。
3. **给每个人一个只属于他的细节**（见 `../archetype-methods.md` 的 1 + 1 + 1）。
