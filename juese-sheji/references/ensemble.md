# 群像拉开

两个以上的主要角色会同场、或者同属一部片的主角组时用。

为什么要单独做：
- **观众要能分清谁是谁**：远景、快剪、背影里，只靠剪影和颜色认人。两个人都是「黑西装、短发、中等身材」，观众就要靠台词去猜。
- **AI 会把人融在一起**：同一个画面里写两个人，模型常常把两个人的脸、发型、衣服互相串（A 的外套跑到 B 身上，两个人长得像兄弟）。两个人描述越像，串得越厉害。
- 拉开不是让每个人都花哨：是让每个人**占据不同的视觉位置**，再用少数共同点表达他们的关系。

## 七个区分轴

每个主要角色在下面七个轴上各占一个位置，任意两个主要角色**至少在 4 个轴上明显不同**，**剪影和主色这两轴必须不同**。

| 轴 | 拉开的办法 | 例 |
|---|---|---|
| 1. 剪影〔全〕 | 体型（高瘦 / 矮壮 / 宽肩 / 圆）× 外轮廓（长大衣到小腿 / 短夹克 / 宽松上身 / 贴身）× 头部轮廓 | 一个高瘦穿长风衣，一个矮壮穿短夹克 |
| 2. 主色〔全〕 | 每人一个主色块（写 HEX），冷暖或明度至少拉开一档；转成黑白也要能分清（明度差） | 一个炭黑 `#1E1F22`，一个驼色 `#A6835A`，一个脏白 `#D9D4C7` |
| 3. 发型轮廓〔全〕〔中〕 | 长短、体积、分线、颜色至少两项不同 | 寸头 vs 中分帘发 vs 扎起的低马尾 |
| 4. 标志性单品〔中〕 | 一人一件，不重复：一个配饰、一件外套、一个随身道具 | 一个永远戴着的黑珍珠吊坠，一个不离手的保温杯 |
| 5. 材质〔中〕 | 光泽、纹理拉开：皮革（反光）/ 针织（毛糙）/ 粗花呢（颗粒）/ 化纤（平滑发亮）/ 亚麻（皱） | 皮夹克 vs 粗针毛衣 |
| 6. 姿态与节奏（动态） | 站姿、走路快慢、手放哪、动作幅度 | 一个总靠墙，一个从不坐下 |
| 7. 说话方式（文字） | 语速、句子长短、称呼习惯 | 一个话多、一个只回两个字 |

## 视觉领地

把主要角色放进「色彩冷暖 × 视觉复杂度」的四格里，**两个主要角色不要落在同一格**：

| | 简单（单色、少件、少配饰） | 复杂（多层、图案、配饰多） |
|---|---|---|
| **暖** | 沉稳、可靠、温和 | 热闹、冲突中心、混乱 |
| **冷** | 疏离、克制、神秘 | 精密、压迫、危险 |

配角和群演：复杂度和饱和度都比主角低一档，不碰主角的主色。

## 关系也要看得出来

拉开的同时，用**一处**共同点表达关系，比完全不同更有戏：
- 一伙人：同一种配饰（同款的银戒、同一个帮派的文身位置）、同一个颜色出现在不同的地方（一个是领带、一个是鞋带）
- 师徒 / 父子：同一件东西的新旧两个版本（师父的旧皮夹克、徒弟刚买的同款）
- 对立：同一个品类的反面（都穿西装：一个合身考究，一个大一号、借来的）
- 弧光：故事走到后面，某人开始穿上另一个人的颜色或物件（同化、继承、背叛）

## 怎么做

1. 先给每个主要角色单独做模式 E，得到各自的维度总表。
2. 填 `../templates/群像对照表.md`：一行一个角色，七个轴各一列。
3. **冲突检查**：两两比较，相同的轴标出来；剪影或主色相同、或者相同的轴超过 3 个，改其中一个人。优先改配角；两个都是主角时，改离他自身设定最远的那一项（不为了拉开去改一个人的身份层）。
4. **远景测试**：只用剪影和主色两列，在脑子里（或画成色块）把所有人排成一排，能不能一眼分清？转成黑白还能分清吗？
5. **领地检查**：放进四格，有没有两个主要角色挤在一格。
6. 写出关系的那一处共同点。
7. 改动回写到各人的人物精细描述（版本号加一）。

## 多人同框的 prompt 写法

- **按位置分段写**，一个人一段，不共用句子：`On the left: …  On the right: …`（或 `Character A (left, foreground): …`）。不要写「two men in black suits」这种合并描述。
- 每个人先写**最能区分他的 2–3 项**（剪影、主色、发型轮廓），再写其他。
- 有参考图就每人一张，写清哪张图控制哪个人。
- 一个画面里只给 1–2 个人写特写细节，其余人只写主设定里的〔全〕〔中〕项。
- 多人镜头更容易串，宁可拆成单人镜头 + 关系镜头（过肩、远景）。

## 审图

多人出图后，按 `drift-checklist.md` 对每个人单独审一遍，再专门看一项：**有没有串**（A 的颜色、发型、单品出现在 B 身上；两个人的脸越来越像）。
