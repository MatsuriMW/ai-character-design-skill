# 评测：具体化到底有没有用、每个模型吞掉什么

回答两个问题：
1. 同一个模糊感觉，**直接写形容词**和**经过模式 E 具体化**，出来的人差多少？
2. 每个模型能保住哪一层细节（〔全〕〔中〕〔特〕），常把哪些写了的东西改回平均值？

结果写进 `../references/model-notes.md`，模式 E 定「一般 / 深入」时按它选，不靠猜。

## 测试用例（`cases.md`）

5 个起点，覆盖气质词、人群、风格三类：

| # | 起点 | 类型 | 主要测什么 |
|---|---|---|---|
| 1 | 轻佻的男性 | 气质词 | 发型、穿法、戴法、姿态这类「中景」细节保不保得住 |
| 2 | 清冷的女性 | 气质词 | 极简造型下，脸部结构和默认表情能不能撑起气质 |
| 3 | 一个老年人 | 人群 | 生活痕迹和做旧（老布鞋上的灰、老年斑、手背青筋）会不会被洗掉 |
| 4 | 有绅士感的中年男人 | 服装风格 | 面料组织（人字纹、粗花呢）、版型细节能不能出来 |
| 5 | 苦命的中年男人 | 气质 + 痕迹 | 不写情绪词、只写形态，苦相能不能自己长出来；会不会退回「演苦」 |

## 每个用例出三组

| 组 | prompt | 构图 |
|---|---|---|
| A 形容词组 | 起点原话直译，只加构图（例：`A frivolous, flirtatious young East Asian man, full body, plain light background.`） | 全身，米白背景 |
| B 主设定组 | 模式 E 的主设定（一般档） | 全身，米白背景 |
| C 深入组 | 主设定 + 特写细节 | 胸像特写，米白背景 |

每组同一模型出 **3 张**（不同种子 / 抽卡 3 次），排除偶然。A、B 构图一致才能比；C 换成特写，专门看〔特〕细节。

## 打分（每张图）

1. **漂移检查**：按 `../references/drift-checklist.md` 逐项打 ✓ / ✗ / —，分别算〔全〕〔中〕〔特〕三层的保住率（✓ 数 / 应出现数）。
2. **平均脸**：是不是一眼 AI 脸（磨皮、全对称、五官标准）：是 / 有一点 / 不是。
3. **盲认**：把 A 组和 B 组的图打乱，给一个没看过 prompt 的人（或者另开一个没有上下文的 agent），只问「这个人给你什么感觉，用两三个词说」。B 组说出原话气质（轻佻 / 清冷 / 老 / 绅士 / 苦）的比例比 A 组高，才说明具体化有效；同时看 B 组有没有比 A 组更「像一个具体的人」。
4. **一句话**：这张图里最像 / 最不像描述的地方。

## 记录

每次评测一个文件：`runs/<日期>-<模型>.md`，用 `run-template.md`。跑完：
- 把各层保住率和常漂的项写进 `../references/model-notes.md`；
- 发现某条写法普遍不管用（比如某模型对「眼梢微下垂」完全无感），改词库里那一条的写法，并在词库里注明。

## 成本提醒

5 个用例 × 3 组 × 3 张 = 每个模型 45 张图。出图大多要花积分 / 额度：**只有用户明确说跑评测、并且说了用哪几个模型，才去生成**。可以先只跑用例 1、3 两个（最能看出区别），18 张。
